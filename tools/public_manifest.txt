# 公開版 (public edition) の定義。docs/editions.md
#
# tools/export_public.sh が git の追跡ファイル (git ls-files) に、このファイルの規則を上から順に当てて、公開版のツリーを作る。
# tools/license_inventory.py が同じ規則から、ファイルごとの「出所 / ライセンス / 公開版へ入れるか」の表を作る。
#
# 方針 (ユーザーの決定): アプリ全体のソース公開を求めるライセンス (GPL 系。LGPL を含む) のコードは、公開版に一切入れない。個人版には全部入れる (配布しない)。
# 許可リスト方式: どの規則にも当たらないファイルは「未分類 = 要確認」で、公開版から除外する (安全側)。
#
# 書式 (空白区切り。# 以降は理由・メモ)。上から順に見て、最初に当たった規則が決める (先に具体的な例外、後ろに一般の規則)。
#   include   <出所> <glob>          公開版にそのまま入れる (SPDX が GPL 系・LGPL 系なら検査が失敗する)
#   relicense <出所> <glob>          公開版に入れ、SPDX を Apache-2.0 に書き換える。自前のコード (出所は own-gpl) で、GPL 系の表記は「GPL 系のライブラリとリンクするため」
#                                    の安全側のラベルだったもの。著作権者 (自分) が公開版で Apache-2.0 として出す。カーネルのコードを含むものには使わない
#   exclude   <出所> <glob>          公開版に入れない
#   reserve   <出所> <glob>          exclude と同じ。まだ追跡されていないファイル (統合前のブランチにあるもの) を先回りして除外する。当たるファイルが無くても古い規則とは見なさない
#   overlay   <出所> <元ファイル> <公開版での置き場所>   公開版専用のファイル (tools/public_edition/ の雛形) を置く。元ファイルは追跡されていること
#   scrub     <出所> s!<正規表現>!<置換>!   書き出す文字ファイルへ全体に当てる置換 (公開版のツリーにだけ効く。個人版のファイルは変えない)
# glob: * は / を越えない、** は / を越える、? は 1 文字。パスは git ls-files の相対パス。
#
# 出所 (origin):
#   own            自前 (このプロジェクトで書いた。外部のコードを写していない)。SPDX は Apache-2.0 か未記載
#   own-gpl        自前だが SPDX が GPL 系 (リンク先の GPL コードに合わせた安全側のラベル。中身にカーネルのコードは無い)
#   own-doc        自前のドキュメント・データ
#   kernel         Linux カーネルのソース (無改変の取り込み。GPL-2.0 系。一部 BSD / 0BSD / zlib)
#   kernel-shim    LinuxCompat 層: カーネルの内部 API (<linux/*.h> とその意味論) を再実装したもの。カーネルのヘッダ・実装に倣って書かれており、派生物として扱う
#   kernel-patch   カーネル由来のコードへのパッチ・解析結果
#   external-gpl   外部の GPL / LGPL プロジェクトを動かす層 (ntfs-3g / wimlib の fuseshim など)
#   dev            開発機・CI・実機検証専用 (公開版では動かない / 個人の環境に依存する / 公開する理由が無い)
#   generated      生成物 (テストの期待値・ベクタ)
